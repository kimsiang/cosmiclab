What's in the package

Three files, three jobs.

cosmic_lab_landing.htmlThe page, with the widget. Replaces your current file. The chat button, panel, and suggested questions are already styled and trilingual.
api/chat.phpThe secure middleman. Holds the conversation rules, rate-limits visitors, and relays messages to the Claude API.
claude_config.sample.phpYour key, kept private. Renamed and placed outside the web folder, so no visitor can ever read it.
→
How it works

The key never touches the browser.

i.A visitor asks a question in the chat widget — in English, Bahasa Malaysia, or 中文.
ii.The widget sends it to chat.php on your own domain, which checks rate limits and attaches the course facts.
iii.chat.php calls the Claude API with your private key and returns a grounded answer.
iv.If anything fails, the visitor sees a polite fallback pointing to hello@cosmiclab.my — never an error.
→
Install · cPanel file manager

Four uploads in ten minutes.

1 · ReplaceUpload the new cosmic_lab_landing.html over your current page in public_html.
2 · Create folderMake a folder named api inside public_html, and upload chat.php into it.
3 · Place the keyRename the sample to claude_config.php and upload it one level above public_html.
4 · Paste the keyEdit that file in cPanel and replace the placeholder with your key from platform.claude.com.
→
Verify

Two checks, and you're live.

Ask a questionOpen the site, tap the blue chat button, and tap a suggested question. A grounded answer should appear within a few seconds.
Switch languageChange the site to BM or 中文 and ask again — the assistant replies in kind.
If it failsA polite fallback message means the key or file path needs a second look. If cURL times out, ask Shinjiru support to confirm outbound HTTPS to api.anthropic.com.
